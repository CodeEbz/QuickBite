# QuickBite Web Portal

The **QuickBite Web Portal** is built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS 4. It features a responsive landing page and dashboard views for **Restaurant Merchants** and **Platform Administrators**.

---

## 📱 Mobile APK Download

- **Android App Package (.APK)**: [Download QuickBite APK](https://expo.dev/artifacts/eas/PjfHlmDs07IXcpGya_Sm93sY4m8e-BK6O0ZvwODc2bU.apk)

*Note: Customers and Drivers access the platform using the Mobile App. Merchants and Admins access this Web Portal.*

---

## 🚀 Features

- **Responsive Landing Page**: Sleek dark ambient design with glassmorphism panels, glowing gradients, and un-crowded mobile layout.
- **Mobile Navigation Drawer**: Toggleable mobile menu header for seamless mobile browsing.
- **Ecosystem Access Cards**: Clear guidance redirecting customers/drivers to the mobile APK download while offering direct portal access for merchants/admins.
- **Merchant Management**: Fulfill kitchen queue orders, update menu items and prices, upload photos, and chat with customers.
- **Admin Control Node**: Audit platform stats, approve/suspend restaurants, manage users, and inspect financial reports.
